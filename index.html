Connect GitHub

Changes are saved to your costume-song-board repo, so every phone sees the same board. This needs a GitHub access key, set up once per device.

Open GitHub with the key filled in
  1. Tap the button above. Name and permission are already set. If GitHub says the name is taken, add a word to the end of the name.
  2. Under Repository access, tap Only select repositories and choose costume-song-board
  3. Scroll down, tap Generate token, then copy the key
  4. Come back to this tab and paste it below
Saved only in this browser on this device. Don't share this page while it's connected.
